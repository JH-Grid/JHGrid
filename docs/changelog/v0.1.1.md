# 0.1.1 - 2026-09-11

[← All releases](../changelog.md)

## Bug Fix

- Canvas had no touch-action, letting native scroll/pinch-zoom/iOS long-press
  callout hijack swipe-scroll, the long-press context menu, and double-tap-to-edit
  on touch devices
- Column/row resize, the fill handle, and the header checkbox used the same 5px
  hit tolerance as mouse, making them hard to grab with a finger; widened the
  tolerance for touch
- The scrollbar thumb/track had no touch handling at all; dragging or tapping it
  did nothing on touchscreens -- now supports thumb-drag and track-tap-to-jump,
  same as mouse
- The column filter panel always opened downward and could get clipped against
  the viewport bottom when the grid was scrolled low on the page; now flips
  upward when there's more room above, like a native <select>
