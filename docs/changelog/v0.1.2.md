# 0.1.2 - 2026-09-13

[← All releases](../changelog.md)

## Fixed
  * Selecting all cells (`Ctrl+A`) and deleting them on a 1,000,000-row grid is now **~12x faster** (reduced from 10+ minutes to ~50 seconds).
  * Optimized memory usage by removing redundant array allocation and string-key parsing during bulk operations.
  * Improved data fetching with chunk caching and capped the demo event logger to prevent DOM bottlenecks.
