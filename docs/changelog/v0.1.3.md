# 0.1.3 - 2026-09-17

[← All releases](../changelog.md)

## Fixed
- Group header labels (`columnDefs[].group`) could render off-canvas and become invisible when a group's last column was only partially visible at the viewport edge.
- The vertical scrollbar track left an unstyled gap next to the header instead of appearing as one continuous bar.
- Set-filter checklist search: typing a value and clicking Apply without touching a checkbox filtered to all values instead of the one typed.
- Tag filter (email/name-style columns): typing a query and clicking Apply without picking a suggestion discarded the query instead of filtering by it.
